# Ellty Design System

First Test Assignment for Ellty.

View it online here: https://ellty-design-system.vercel.app/

## 🚀 Features

- **React 19**
- **Next.js 16** - Built on Next.js App Router
- **TypeScript**
- **Tailwind CSS 4** - Utility-first CSS framework
- **Vercel Ready**

## 🛠️ Getting Started

### Prerequisites

- Node.js 18+ installed
- npm or yarn

### Installation

1. Clone the repository:

```bash
git clone https://github.com/a-billet/ellty-design-system.git
cd ellty-design-system
```

2. Install dependencies:

```bash
npm install
```

3. Run the development server:

```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## 📝 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm start` - Start production server
- `npm run lint` - Run ESLint
